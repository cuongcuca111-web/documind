# DocuMind - Tóm Tắt & Trực Quan Hóa Tài Liệu (AI Visualizer)

Ứng dụng web trực quan hóa tài liệu, tự động tạo sơ đồ tư duy (Interactive Mindmap bằng D3.js), lưu đồ tiến trình (Flowchart bằng Mermaid.js) và biểu đồ phân bổ trọng tâm tri thức.

## Tính năng chính
- 📄 Hỗ trợ tải tệp: PDF, DOCX (Word), TXT, Markdown hoặc liên kết Google Docs.
- 🧠 Vẽ sơ đồ tư duy động (Interactive Mindmap) thu phóng, đóng/mở nhánh.
- 🔄 Lưu đồ phân tầng logic (Mermaid Flowchart).
- 📊 Biểu đồ trực quan hóa trọng số kiến thức (Radar & Doughnut Chart).
- 💬 Trợ lý hỏi đáp nhanh nội dung tài liệu.
- ⚙️ Tùy chọn cấu hình Gemini API Key trực tiếp trên trình duyệt.

## Hướng dẫn chạy
Trang web được xây dựng hoàn toàn phía client (Single Page Application). Bạn chỉ cần mở tệp `index.html` bằng bất kỳ trình duyệt nào hoặc triển khai miễn phí lên GitHub Pages.
